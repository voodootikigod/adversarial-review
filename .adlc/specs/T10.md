# T10 — First-class Vercel AI Gateway provider + one-key multi-family routing

## Problem

Vercel AI Gateway is only reachable today as a generic OpenAI override
(`--provider openai --api-base …`). There is no `AI_GATEWAY_API_KEY` auto-detect
and no way for `--providers` to fan across openai/anthropic/gemini families with
a single Gateway key. Current docs use `https://ai-gateway.vercel.sh/v1` with
`provider/model` ids and OpenAI Chat Completions `json_schema` — compatible with
our existing openai fetch path.

## Fix

### Single-provider

`--provider vercel` (alias `gateway`):

- `apiBase` default `https://ai-gateway.vercel.sh/v1` (override: `--api-base`,
  `AI_GATEWAY_API_BASE`, `AI_GATEWAY_BASE_URL`)
- Auth: `args.apiKey || AI_GATEWAY_API_KEY || VERCEL_OIDC_TOKEN`
- Default model: `anthropic/claude-sonnet-4.6`
- Route through the existing OpenAI Chat Completions + `json_schema` client
  (zero new deps; no AI SDK)

### Multi-provider (highest leverage)

When resolving a family token for `--providers` / `--providers auto`:

Order per family: **native API key → Gateway (if AI_GATEWAY_API_KEY or
VERCEL_OIDC_TOKEN) → local CLI**.

Gateway model ids:

| Family | Gateway model |
|--------|---------------|
| openai | `openai/gpt-5` |
| anthropic | `anthropic/claude-sonnet-4.6` |
| gemini | `google/gemini-2.5-pro` |

Native vendor key wins when both native and Gateway credentials exist.
CLI-only tokens (`codex`/`claude`/`agy`) never upgrade to Gateway.
Explicit `--provider openai` with only a Gateway key **errors** (no silent
redirect). Opt-in single-provider path is `--provider vercel`.

Gateway is a **transport**, not a diversity family (D5).

### Auto-detect

If no vendor keys and no local CLIs but `AI_GATEWAY_API_KEY` (or OIDC) is set,
select `provider=vercel`. Inside Claude Code / Cursor env branches, prefer
Gateway routes that reach a **non-builder** family before falling back to the
builder's own family.

  `AI_GATEWAY_API_KEY` throws/errors.
  Verification: `node --test test/llm.test.js` (no-silent-redirect case).

- **AC6 (auto-detect)** — Only `AI_GATEWAY_API_KEY` set → auto-detect selects
  `vercel`.
