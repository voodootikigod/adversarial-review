# T9 — Replace broken Cursor local-proxy provider with official `agent` CLI

## Problem

`--provider cursor` and the Cursor-env auto-detect fallback target
`http://127.0.0.1:8765/v1` with a dummy API key. That host is a third-party
`cursor-api-proxy` convention, not a Cursor product surface. Cursor IDE does
not start it; local probes get connection refused. Reviews that fall back to
"Cursor's local LLM proxy" fail with a misleading story.

## Fix

Treat Cursor as a **local CLI provider** via the official Agent CLI (`agent`,
also shipped as `cursor-agent`):

```
agent -p --mode plan --trust --output-format text [--model <m>] -
```

Prompt on stdin (`-`), with argv fallback + size guard (same pattern as
`callCliLLM`). Force `--mode plan` by default so untrusted diffs cannot
prompt-inject writes (`-p` alone grants write/shell tools). Escape hatch:
`--allow-unsandboxed-cli` omits `--mode plan`.

### Design locks

| ID | Decision |
|----|----------|
| D1 | Transport = CLI. Tokens `cursor` and `agent` → `provider:"cli"`, `cliCmd:"agent"` (prefer `agent` over `cursor-agent`). Remove HTTP `knownApis` cursor path and `8765` defaults. |
| D2 | Argv as above; do **not** reuse Claude `--permission-mode plan`. |
| D3 | Keep cursor/agent out of `--providers` family tables (no fake diversity). |
| D4 | Pass `--model` only when `args.model` is set. |
| D5 | Scrape JSON via `cleanJsonResponse` (no `--output-schema`). Prefer `--output-format text`. |
| D6 | Loop fixer: do **not** auto-select `agent`. Explicit `--loop-fixer agent\|cursor-agent` allowed; map family `"cursor"` for bias warnings. |

## Out of scope

- `@cursor/sdk` (zero-deps package)
- Bundling/starting any localhost proxy (users keep `--provider openai --api-base …`)
- Making cursor a `--providers` family
- Vercel AI Gateway (T10)
- Changing `schema.json`

## Acceptance criteria

- **AC1 (configure)** — `configureLLM({provider:"cursor"})` with `agent` on mocked PATH returns `{provider:"cli", cliCmd:"agent"}` and does **not** set `apiBase` to `127.0.0.1:8765`.
  Verification: `node --test test/llm.test.js`.

- **AC2 (auto-detect)** — `TERM_PROGRAM=cursor`, no API keys, only `agent` on PATH → `cliCmd==="agent"` (same-provider warn allowed).
  Verification: `node --test test/llm.test.js`.

- **AC3 (argv isolation)** — `llmCall` for `cliCmd=agent` invokes argv containing `-p` and (`--mode`+`plan` or `--plan`); default path is not unsandboxed tool mode.
  Verification: mock binary records argv in `test/llm.test.js`.

- **AC4 (escape hatch)** — `--allow-unsandboxed-cli` omits `--mode plan` / `--plan` for agent.
  Verification: unit test in `test/llm.test.js`.

- **AC5 (proxy gone)** — `src/` contains no `8765` string after the change.
  Verification: test assertion or `grep -n 8765 src/` empty.

- **AC6 (no fake diversity)** — `--providers auto` never selects cursor/agent as a diversity family.
  Verification: `test/multiprovider.test.js` assertion; existing suite stays green.

- **AC7 (suite)** — `npm test` exits 0.
  Verification: `npm test`.
